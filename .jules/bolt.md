## 2026-09-05 - Memoizing Redux Selectors\n**Learning:** Derived values in Redux selectors (like `flatMap` or `reduce`) return a new reference on every state update, triggering unnecessary re-renders in React components relying on those selectors, even when unrelated parts of the state change.\n**Action:** Always use `createSelector` from `@reduxjs/toolkit` to memoize derived state when the data involves complex transformations or returning new array/object references.
